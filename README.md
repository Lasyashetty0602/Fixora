# Fixora

Fixora is a web-based building maintenance and issue reporting application.

## Features
- User registration and login
- Report maintenance issues
- Track issue status
- Admin dashboard to manage reported issues
- Backend API for authentication and issue management

## Tech Stack
- Frontend: React and Vite
- Backend: Node.js and Express
- Database: MongoDB

## Project Structure
- `client/` — Frontend application
- `server/` — Backend application

## Getting Started
Install the dependencies separately in the `client` and `server` directories using `npm install`.

Configure the required environment variables before starting the application.
